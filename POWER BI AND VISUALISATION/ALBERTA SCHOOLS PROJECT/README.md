## Overview
This project focuses on analyzing school-related data in Alberta to uncover trends, compare performance across regions, and provide a clearer view of how schools and communities are performing. The goal was to transform raw education data into a business-ready dashboard that supports evidence-based decision-making.

The dashboard is designed to help stakeholders and parents understand key patterns in school performance, enrollment, regional differences, and other metrics that matter for planning and evaluation.

## Business Problem
Education leaders, parents, guardians and planning teams often need to understand how schools perform across a province, but data is frequently spread across multiple sources and difficult to interpret quickly. Without a clear summary, it becomes challenging to identify trends, compare schools, and make informed decisions about resources and support.

This project addresses that challenge by bringing relevant indicators into a single, accessible Power BI dashboard.

## Objective
The objective of this project was to create an interactive, presentation-ready dashboard that:

- provides a high-level view of school performance,
- highlights differences across schools and regions,
- supports comparisons using key education metrics,
- and makes the data easier to interpret for business and policy stakeholders.

## What Was Built
The project includes a Power BI dashboard that brings together important education indicators in a structured and visually engaging format. The report is designed to provide both summary-level insight and the ability to explore data in more detail.

### Key dashboard elements
- School and regional performance comparison
- Enrollment and participation trends
- Geographic or area-based analysis
- KPI summary cards for quick review
- Interactive filters for focused exploration
- Clean presentation layout for stakeholder use

## Key Metrics
The dashboard can be used to track and compare the following types of information:

- Enrollment counts
- School performance indicators
- Regional comparison metrics
- Program or demographic segmentation

## Skills Demonstrated
- Power BI dashboard design
- Data cleaning and preparation with Power Query
- Data modeling and relationship creation
- DAX measures for KPI development
- Data visualization for business communication
- Insight generation and storytelling through dashboards

## Value to Stakeholders
This project demonstrates how data visualization can help education organizations make more informed decisions. Instead of working from scattered reports or raw data tables, stakeholders can explore trends and comparisons in an intuitive dashboard designed around their decision-making needs.

The result is a clearer understanding of where performance is strong, where support may be needed, and how schools compare across the province.

## Outcome
This project is a strong example of how Power BI can turn education and public-sector data into a strategic tool. It moves beyond reporting and into insight generation, helping stakeholders interpret patterns more clearly and make better-informed decisions.
