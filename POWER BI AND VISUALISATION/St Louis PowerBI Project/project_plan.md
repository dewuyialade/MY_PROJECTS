# St Louis PowerBI Project Plan

## Objective
Create a polished Power BI dashboard that highlights key trends in St. Louis across demographics, housing, neighborhood performance, and public safety.

## Phase 1: Data Collection
- Gather neighborhood data
- Include population, income, and housing information
- Collect crime and permit data
- Prepare a time dimension table

## Phase 2: Data Modeling
- Standardize field names
- Create lookup tables for neighborhoods and ZIP codes
- Build star schema relationships
- Define DAX measures for KPIs

## Phase 3: Dashboard Design
- Home page with key KPIs
- Neighborhood comparison page
- Housing trend page
- Safety and public services page

## Phase 4: Interactivity
- Add slicers
- Create drill-through pages
- Add bookmarks and navigation buttons
- Include both static and dynamic tooltips

## Phase 5: Review and Presentation
- Validate calculations
- Check dashboard usability
- Prepare final business summary and recommendations

## Example KPIs
- Median household income
- Population growth
- Home value average
- Crime incidents per 1,000 residents
- Permit approvals
- Vacancy rate

## Suggested Visuals
- KPI card visuals
- Filled map
- Stacked column chart
- Line chart for trends
- Scatterplot for correlation analysis
- Matrix for detailed comparison
