# St Louis PowerBI Project

## Overview
This project is a Power BI dashboard concept designed to help stakeholders explore key trends across the St. Louis metro area. The dashboard is intended to provide a clear view of economic, demographic, housing, and neighborhood-level conditions using a single interactive reporting experience.

## Project Goal
The purpose of this project is to turn raw city and regional data into actionable insights for:

- Business leaders
- City planners
- Community organizations
- Investors and developers
- Public policy teams

## Core Business Questions
- Which neighborhoods are growing the fastest?
- Where are housing prices rising or falling?
- Which areas have strong employment or commercial activity?
- What regions are seeing the greatest demand for housing or services?
- How do neighborhood characteristics compare across the city?

## Suggested Dashboard Structure

### Page 1: Executive Overview
Key metrics and summary visuals:
- Total population
- Median household income
- Average home value
- Crime rate trend
- Unemployment rate
- Number of active business permits

Visuals to include:
- KPI cards
- Line chart for yearly trends
- Bar chart for neighborhood comparison
- Map visualization of St. Louis area by ZIP code or census tract

### Page 2: Neighborhood Comparison
Explore local performance and conditions:
- Population by neighborhood
- Housing pricing by area
- Vacancy rate
- Poverty rate
- Median rent
- Business density and commercial activity

Visuals to include:
- Clustered bar charts
- Heat map or filled map
- Matrix table with drill-through support
- Slicers for neighborhood, ZIP code, and year

### Page 3: Housing & Development
Focus on property and investment trends:
- Home sales volume
- Median sale price
- Permit approvals
- New construction activity
- Foreclosure or distress indicators

Visuals to include:
- Area chart for housing trend
- Scatter plot for price vs. income
- Treemap for development activity
- Drill-through details by neighborhood

### Page 4: Safety & Community Insights
Assess quality-of-life indicators:
- Crime incidents by category
- Crime trend by month and year
- Neighborhood safety index
- Public services coverage

Visuals to include:
- Column charts
- Decomposition tree
- Map by incident location
- Stacked bar chart by crime type

## Suggested Data Sources
Use publicly available data, local government reporting, or business datasets such as:

- U.S. Census data
- St. Louis city and county demographic data
- Housing and sales data
- Crime and safety reports
- Permit and development records
- Employment and wage data

## Recommended Power BI Features
- Slicers for neighborhood, ZIP code, and time period
- Drill-through pages for neighborhood detail
- Bookmarks and navigation buttons
- Tooltips for contextual metrics
- Dynamic KPI cards
- Filled map for location-based analysis

## Data Model Ideas
Create tables such as:
- Demographics
- Housing
- Crime
- Business Activity
- Neighborhood Lookup
- Time Dimension

Suggested relationships:
- Neighborhood table to Demographics, Housing, and Crime
- Date table to all time-based metrics
- ZIP code or census tract table to geospatial visuals

## Design Concept
Use a clean city-focused visual style with:
- Deep blue, gold, and gray tones
- High-contrast KPI cards
- Modern font styling
- Map-driven layout with strong narrative storytelling

## Deliverables
- Interactive Power BI dashboard
- Clean data model
- Report documentation
- Summary insights with recommendations
